# DocMaster releases

Installers and updates for **DocMaster**, a private, offline document desk for Mac (convert, merge, compress, lock, sign, OCR and more; your files never leave your Mac).

## Install

1. Download the latest `DocMaster-<version>.dmg` from [Releases](https://github.com/notnishantgoel/docmaster-releases/releases).
2. Open it and drag **DocMaster** to **Applications**.
3. The first time, right-click DocMaster and choose **Open** (the app isn't notarised by Apple).

Word, PowerPoint and Excel files need [LibreOffice](https://www.libreoffice.org) (`brew install --cask libreoffice`). Making scans searchable needs Tesseract (`brew install tesseract`).

## Updates

In the app: **DocMaster ▸ Check for Updates…**. Updates are signed; the app only installs ones signed with DocMaster's key.

This repository only holds the release files.
